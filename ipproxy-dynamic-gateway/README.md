## 地区代码说明

- 动态代理连接串上的：国家、省份、城市代码
- 进入 `BasicAuthenticator` 逻辑后直接提取连接串的代码，保持原来的大小写

### 普通池

- country 为 any 时，使用 `随机地区粘性/一次一换` 连接串格式。不涉及任何地区代码
- country 为给定值时，使用 `指定地区省份粘性/一次一换` 连接串格式，forward连接串的country值根据供应商的 `areaCaseType` 字段判断是否大小写，若值为1则转换为大写，值为0则转换为小写
- 省份和城市给定值时，使用 `指定地区省份粘性/一次一换` 和 `指定地区省份城市粘性/一次一换` 连接串格式。最终连接串的state和city值则原样按照输入连接串的值，不作修改

### 融合池

进入融合池的规则
- 当客户随机到的供应商id为 `16` 或 `17` 时，则进入融合池映射规则

地区转换规则
- country 为 any 时，跟普通池一样，使用 `随机地区粘性/一次一换` 连接串格式。不涉及任何地区代码
- country 为给定值时，使用 `指定地区省份粘性/一次一换` 连接串格式，forward连接串的country值根据供应商的 `areaCaseType` 字段判断是否大小写，若值为1则转换为大写，值为0则转换为小写
- 省份和城市给定值时，使用 `指定地区省份粘性/一次一换` 和 `指定地区省份城市粘性/一次一换` 连接串格式。最终连接串的state和city的值按照映射规则转换为映射表的值，具体如下
  - 若映射的值为空，或者供应商不支持该粒度的值，则回退到上一级的支持转换的粒度
  - 否则按照映射表获取值
  - 若最终查找不到，则返回错误
